The API, documented by the database itself

This page renders the OpenAPI spec that PostgREST generates live from the schema — every table, view and function shown here is exactly what the browser role can reach, and the description below the title is a database comment stating what was deliberately left out. Nothing on this page is hand-written, so it cannot drift.

Try it: expand POST /rpc/search_deals and execute a query — the same call the prototype makes. The one write path, POST /demand_events, is real too: rows you insert land in the demand table the staff panel reads.
